### 1.5 Выводы для продукта (из чартов)

1. **Для RU/CIS merge — жанр №1 по деньгам (28 % grossing-топа)**, и одновременно самый «мерджевый» рынок из трёх.
2. **Чистый merge-2 — красное море**; растёт стык **merge + TD/idle-battler** (Tiles Survive, Castle Busters, Kingshot).
   Наша связка «merge-сетка → автобой на дорожках → idle-улей» попадает ровно в этот стык.
3. Скачиваемость делают микропазлы, а **деньги делает мета**: сезон, коллекция, звёзды, idle. Значит мета-слой
   обязателен и должен быть виден с первого экрана.
4. В России **нет казино-слотов в топе** → монетизация через косметика/бустеры/пропуск, а не «рулетка за деньги».
5. Ротация 12–14 месяцев ⇒ игра должна давать «вау» и виральность в первую минуту, без разгона в 20 сессий.
6. **Турецкая волна** пазлов (Grand/Lumi/Loop/Powerfantasy/ABI Global) оккупировала free-топы: конкурировать с ними
   за загрузки бессмысленно — конкурировать нужно за удержание и «пересылку другу», то есть за Telegram-специфику.

### 2.3 Антипаттерны (из-за чего умерли предшественники) → наши дизайн-ограничения

1. **Перенос/обесценивание аирдропа** — Hamster: после переноса <100 млн уже в августе 2024.
2. **Аирдроп как финал игры** — 17,8 % удаляются сразу после раздачи, ещё 50,6 % резко снижают активность (ChainPlay, опрос 957 игроков).
3. **Страх вместо интереса** («не зашёл 3 часа — прогресс сгорел») + интерес к жанру −80 % за полгода.
4. **Игрок как товар**: CPA-реклама бирж вместо игровых ценностей.
5. **Токен/NFT раньше продукта** — главный вывод post-mortem 2026 (93 % мертвы, Pixelmon $70 млн и 4 года без игры).
6. **Метрика «зарегистрировано» вместо DAU/удержания** (Animoca: 60 %/25 % удержания пика).
7. **Инфраструктура вместо геймплея**: Hamster Network L2 — −99,9 % объёма за 2 недели (13.03.2025).
8. **Прямая квалификация жанра платформой**: TON Foundation (А. Шмалко, 08.12.2024) — tap-to-earn был
  «коротким механизмом онбординга, а не долгосрочным решением».

### 2.4 Требования к продукту (вывод ресёрча, 12 пунктов)

1. Не токен-первый продукт; в первой сессии — играбельная сборка, а не обещание.
2. Сессия **2–5 минут** с осмысленным финалом + одна «длинная» механика 10–15 мин в день; никакого сгорания прогресса.
3. Удержание через **социальные обязательства** (дуэль, клан, общая цель), а не через страх потери.
4. Инвайды с прозрачной атрибуцией (`startapp=` + партнёрка Stars) вместо закупки дешёвого трафика.
5. Возврат через бота (`requestWriteAccess`) с игровым поводом, ≤1–2 сообщения в неделю.
6. Монетизация: Stars-подписка (2–3 тарифа) + косметика/удобство + paid media; диапазон цен задают лимиты
   10 000 / 25 000 Stars.
7. Подарки = редкие трофеи, а не «вывод».
8. Никакой обязательной внешней рекламы в ядре.
9. Онбординг в одну руку, мгновенная играбельность, ярлык на домашний экран как цель.
10. Лидерборды собственные (бот + БД), еженедельный сброс, командная таблица, публикация в чат/Story.
11. Ориджин один, HTTPS, идемпотентный сервер, события `BotSubscriptionUpdated` обрабатывать сразу.
12. Метрики: D1/D7/D30, % удержания пика DAU (цель >60 %), платящая доля/ARPPU в Stars, K через `shareMessage`.

**Открытый риск (проверяется):** доступность покупки Stars для пользователей из РФ в 2026 — если ограничена,
витрина должна корректно «гаснуть» для RU-аудитории, а ядро оставаться полностью играбельным. `[не проверено]`

## 3. Технические возможности платформы (Bot API 10.3 от 24.08.2026)

Источник: снимки web.archive.org официальных страниц `core.telegram.org/bots/webapps` (27.10.2026), `bots/api`
(05.11.2026), `bots/games` (05.10.2026), `bots/payments` (25.10.2026), `bots/payments-stars` (06.11.2026),
`telegram.org/blog` (05.11.2026) + типы `@types/telegram-web-app@10.1.0` (29.08.2026). Полная версия со всеми
сигнатурами: [.research/telegram-miniapps-2026-report.md](../.research/telegram-miniapps-2026-report.md).
Сами `core.telegram.org` / `t.me` из этой среды **не отвечают** — только архив.

### 3.1 Что определяет архитектуру игры

* **CloudStorage: value ≤ 4096 символов, ключ 1–128 симв. только `A-Za-z0-9_-`, максимум 1024 ключа** на пару
  bot×user. Методы `setItem/getItem/getItems/removeItem/removeItems/getKeys` (`getCommands` не существует).
  ⇒ **сейв обязан компактным и разрезанным на ключи `nh_s1..nh_sN`**, запись — дебаунс, чтение — одним `getItems`.
* `localStorage`/IndexedDB в WebView **ненадёжны** для прогресса ⇒ localStorage только как кэш/браузерный фолбэк.
  DeviceStorage (9.0+) — локально без синхронизации, SecureStorage (9.0+) — токены/рефер-коды.
* `WebApp.init()` **не существует** — только `ready()`. `WebApp.version` = версия Bot API в клиенте, есть
  `isVersionAtLeast(v)` ⇒ гейтим фичи по версиям (fullscreen 8.0, shareMessage 8.0, DeviceStorage 9.0, Serverless 10.2).
* Обязательный стартовый ритуал: `ready → expand → requestFullscreen → lockOrientation → disableVerticalSwipes →
  setHeaderColor/setBackgroundColor`. Свайпы вниз по умолчанию съедают игровые жесты.
* Пауза/сейв на `deactivated` (+ `isActive`, 8.0+), размеры на `viewportChanged{isStateStable:true}`,
  `safeAreaChanged`/`contentSafeAreaChanged`, `safeAreaInset`/`contentSafeAreaInset`; CSS-переменная
  `--tg-viewport-stable-height`; на Android bottom-inset часто 0, на iOS ~34 px.
* `platform`: android|ios|android_x|webm|weba|macos|windows|linux; отдельного `deviceType` нет.
* Нет лимита на размер бандла, но WebKit iOS убивает вкладку при ~1–1.5 ГБ RAM ⇒ ориентир first paint
  ≤1.5–2 МБ gzip. **Наш подход (0 ассетов, процедурный canvas + синтез звука) попадает идеально.**
* iOS: звук только после пользовательского жеста (`AudioContext.resume()`), программный focus невозможен,
  `hideKeyboard()` с 9.1.
* Чего нет (мифы из старых туториалов): `setColorScheme`, `DataCustom`, `WriteAccess`, `ScanQrPopup`-объект,
  `CloudStorage.getCommands`, `allowsPageScrolling`. `invokeCustomMethod` — только из community
  `@telegram-apps/bridge@2.11.0`, в официальной доке Mini Apps его нет.

### 3.2 Монетизация — важная поправка

* **Цифровые товары внутри Telegram — исключительно Telegram Stars** через Bot Payments API; внешние платёжки
  (включая TON Connect) для покупок в игре **запрещены правилами**. TON остаётся только «вывод Stars через Fragment».
  ⇒ в `MARKET.md` ранняя ставка «оплата в TON» некорректна: витрина = Stars (`currency="XTR"`, пустой
  `provider_token`, одна `prices`), `createInvoiceLink` → `openInvoice(url, cb)` → `invoiceClosed{paid|cancelled|...}`.
* Подписка доступна **только** через `createInvoiceLink` c `subscription_period` ∈ {7,30,90,180,365} суток —
  в `sendInvoice` этого поля нет. Хранить `telegram_payment_charge_id` (нужен для `refundStarPayment`).
* Бесплатные сигналы: `initDataUnsafe.user.is_premium`. Партнёрка `AffiliateInfo{commission_per_mille,...}` —
  готовая реферальная экономика на Stars. Stars тратятся на Telegram Ads. Paid-broadcast рассылка: 0.1 Star/сообщение,
  требует ≥100 000 Stars и ≥100 000 MAU — на старте недоступно.
* Социалка/виральность: `switchInlineQuery` (шар в любой чат), `shareMessage` (8.0+), `shareToStory` (7.8+,
  текст 0–200 / 0–2048 premium), `start_param` / `tgWebAppStartParam` для инвайдов, `addToHomeScreen` (8.0+).
  `web_app`-кнопки работают **только в приватных чатах**, в группу — только `url`.

### 3.3 Games platform vs Mini Apps

Games platform = HTML5 в in-app браузере с API из двух методов (`games.js`: `TelegramGameProxy.shareScore()`),
лидерборд `setGameScore`/`getGameHighScores` привязан к сообщению/чату (`chat_instance` как ключ), страница
`/bots/games` не менялась с 2022. **Решение: ядро — Mini App**; опционально «карточка» `sendGame` ради
чатового лидерборда и превью. Глобальный тод — свой бэкенд, в локальной версии — сид-лист + собственные рекорды.

### 3.4 Что меняем в нашей реализации (дописывается в GDD)

1. Сейв: компактный сериализатор (короткие ключи/сжатие), чанки ≤4096, батч-чтение, дебаунс-запись, зеркалирование
   в localStorage для браузера; миграция по префиксу версии в имени ключа (`v2_save1`, точку в ключе ставить нельзя).
2. Стартовый ритуал + `disableVerticalSwipes` + `lockOrientation('portrait')` + фолбэк в браузере без SDK.
3. Витрина Stars вместо TON-платежей; реальная оплата — за заглушкой бэкенда (по решению пользователя «локально +
   заглушка API»), кнопка «PREMIUM» подсвечивается по `is_premium`.
4. Инвайды/шар: `startapp=` параметр + `switchInlineQuery`; «ЭХО-карточка» друга уходит инлайн-кверией.
5. Гаптика на коллизии/мердж (HapticFeedback impact/notification/selection), звук — после первого тапа.
6. Отладка: iOS — 10 тапов по Settings → Allow Web View Inspection; Android — зажать номер версии → WebView Debug.
7. **Стек — сознательное отклонение от рекомендации агента** (Vite + TS + PixiJS v8): остаёмся на сборке без

   спрайтовый атлас и >2000 объектов».
8. **Конкретные правки в уже написанном коде (когда вернёмся к сборке):** `D.SHOP` — цены из «TON» в Stars/XTR;
   `NH.TG` — добавить `CloudStorage`-адаптер сейва (чанки ≤4096, батч-чтение, дебаунс-запись) и стартовый ритуал

   сейва + зеркалирование в localStorage; `js/platform.js` — не использовать `WebApp.init()`, гейки по

### 4.3 First-run (60 секунд решают)

* Правило GameAnalytics: **обучение : практика = 1 : 2,5**, подсказка **≤2–8 слов** (Джордж Фэн, PvZ), начинать
  с образа/истории, а не с меню; обязателен performance feedback (цифры в лицо) и сбор событий.
* Целевой тайминг: **0–3 с** — игра уже на экране, первый мердж сделан тапом; **5–10 с** — первый «wow»
  (склейка двух топов → вспышка + число + дроп); **20–30 с** — завершён первый забег, виден итог и мета-награда;
  **45–60 с** — показана петля «забег → мета → цель»; **60–120 с** — второй забег с модификатором;
  **paywall/энергия — не раньше 3-го забега**.
* Смертельные ошибки: онбординг-текст, требование кошелька/регистрации до игры, показ всех систем сразу,

### 4.4 Наши «изюминки» глазами исследования

**Эхо (асинхронные призраки) — механика с отраслевым подтверждением.** Dark Souls: призраки показывают скрытые
проходы, **пятно крови проигрывает последние секунды чужой смерти**, а сама схема стала источником async-функций
PSN (Wikipedia). Подача: **имя вместо абстракции** («Артём прошёл это за 0:52 — 6 410», кнопка «Сыграть его расклад»),
бейдж «человек», авто-шер после обгона («Я обошёл Артёма на 380 очков» через `shareMessage`), собственное
«пятно» после проигрыша («здесь ты потерял ×4 — забери в следующем забеге»), «эталон недели» в клане.
Риски: мусорные/читерские забеги (фильтр по человеческим границам), рассинхрон рандома (**реплей обязан включать seed**),
выдача NPC за друзей (нельзя).

**Двунаправленный мердж — вторичная механика, не ядро** (прямых источников по «reverse merge» как ядру нет, `[не проверено]`).
Плюсы: мгновенный микро-прогресс, лечит главную фрустрацию merge-2 — забитую доску, превращает мусор в валюту,
даёт решение без новых правил. Минусы: ярость от случайной необратимости, размывание цели при курсе выше ~60 %
стоимости апгрейда, шум на доске. Правила подачи: назвать **«переплавить»**, показывать превью результата,
обучать одним моментом, где доска забита, подтверждение на редкостях 4+, **курс ≈ 50 % апгрейда**.
⇒ Итог: **Эхо = ядро виральности и K-фактора; Переплавка = вторая по важности «изюминка»** (мутации тактика
остаются внутри расщепления, но не становятся главным нарративом).

### 4.5 Монетизация в мессенджере

* **Rewarded CPM в 30–100 раз выше обычных плейсментов**; реклама = **23 % чистой выручки** моб. игр; rewarded
  **каннибализирует IAP «продолжить/бустер»** ⇒ **каталог покупок не должен пересекаться с ад-петлёй** (Sensor Tower/DoF).
* Rovio (Angry Birds Dream Blast): **риск потерять плательщика выше ад-выручки**; награды «съедают» друг друга;
  interstitial — только не-rewarded-сегменту; считать «video whales (100+ просмотров)».
* Lестница merge-2: энергия 10 → 20 → 40 гемов, **сброс цен ежедневно**; три якоря цены (~0,99 / 4,99 / 19,99)
  с завышенной ценностью среднего; Stars — для мелких покупок.
* Telegram Stars: цифровые товары только через Stars (решает соответствие политике Apple/Google по цифровым товарам);
  вывод в TON через Fragment **через 21 день**; курс/доля разработчика — `[не проверено]`.
* Рекомендуемая архитектура: rewarded 3–5 показов/сессию (ожиить, ×2 оффлайн, +1 выбор модификатора, реформа серии),
  никогда как единственная награда за прогресс; IAP/Stars — сезон, косметика, «детали» базы; подписка = сезон +
  +1 энергия/час; **сегмент «плательщик» не видит rewarded-офферов**.

### 4.6 Виральность: только нативные примитивы Telegram

`t.me/<bot>?startapp=<param>` → `start_param` / `tgWebAppStartParam` — точная атрибуция инвайта без cookie;
`mode=compact` + `chat_type`/`chat_instance` — соревнование внутри группы; **`shareMessage` — шар медиа-карточкой,
а не ссылкой** (выше конверсия, чем у «поделись и получи»). Что нельзя: forced-share wall, обещания выплат за инвайт,
накрутка цепочек. K-фактор для Telegram-игр в открытых источниках отсутствует — **измерять самим через `start_param`**.

### 4.7 Метрики первого билда

D1/D7/D30 относительно якорей (касуал D7 21–25 %), ASL, показы/юзер, воронка `start_param`

## 6. Финальная продуктовая спецификация — «НЕОНОВЫЙ УЛЕЙ / NEON HIVE»

**Одной фразой.** Telegram-игра, где за 90 секунд ты merges’ом собираешь улей, который сам отбивает волну:
**merge-2 как двигатель желания + TD-поле как читаемый прогресс + асинхронные «Эхо» как причина вернуться и переслать.**

### 6.1 Ядро-луп (забег 90–110 с)
1. **Сетка улья 4×4**: генератор даёт «соты» 1-го уровня; тап по двум одинаковым — склейка вверх (merge-2-стиль).
2. Готовые соты **перетаскиваются на 4 дорожки обороны** — ряд башен читается как TD-прогресс без обучения.
3. **Волна** идёт снизу вверх к реактору; автобой юнитов; забег заканчивается волной или забитой сеткой.
4. **Финал забега →performance-экран** (цифры в лицо: очки, жатва, мёд) → **драфт 3 модификатора** («1 строка + 1 число») →
   мета-награда (улей/коллекция) → «Ещё раз» или «Эхо».
5. **Ядро на навыке, а не на тапах**: позиционирование, тайминг склейки, курс переплавки, выбор модификатора.

### 6.2 Две изюминки (подаются именно так)
* **ЭХО** — асинхронный призрак реального забега (своего или друга), идёт рядом по своей дорожке и добавляет свой DPS.
  После забега: «**Артём прошёл это за 0:52 — 6 410**» → «**Сыграть его расклад**» / «**Обогнать Артёма**»;
  обгон → авто-шер карточкой `shareMessage` («Я обошёл Артёма на 380 очков»). Бейдж «человек» и строка доверия
  «призраки — реальные забеги, не боты». Собственный проигрыш оставляет «**пятно**»: «здесь ты потерял ×4 — забери
  в следующем забеге». Реплей воспроизводится по **seed**, поэтому расклад повторяем один в один.
* **ПЕРЕПЛАВКА / РАСЩЕПЛЕНИЕ** — второй жест на доске: соту можно расщепить на две младшие с **броском мутации**
  (blaze / hoarfrost / arc / toxin / ricochet / overshoot / dynamo / twinshot) либо переплавить в «детали» по курсу
  **≈50 % стоимости апгрейда**. Превью результата на иконке, подтверждение на редкостях 4+, обучение — одним
  моментом, где сетка забита.

### 6.3 Мета
**Улей** (merge-стройка: 5 тапов до видимого апгрейда) · **коллекция 12 линий** + звёзды · **сезон 21 день**
(бесплатная дорожка обязательна) · **лига на 8 человек, ротация 3 дня** (награды косметикой) ·
**клан = группа Telegram** (`chat_instance`) с командной целью недели · **престиж** «пересборка улья» + постоянный трофей.

### 6.4 Возврат и ивенты
**Энергия «нектар»**: кап **8**, реген **1 / 4 мин**, забег = 1; **дуэли, Эхо и клановая лига — без энергии**
(урок Coin Master: троттлинг только на основном режиме). **Полоса дня**: 3 квеста из одного забега.
**Серия забегов** + «щит серии» раз в месяц + streak-reform за 1 просмотр / 20 Stars в окне 24 ч.
**«Ярость роя»**: 48-часовой ивент с общим модификатором (например «переплавка ×2»), участие = 1 забег.
Оффлайн-доход копится в улье, ×2 за просмотр — **и никогда плательщикам**. Возврат ботом — ≤1–2 сообщения в неделю,
только с игровым поводом (ответ соперника, конец ивента).

### 6.5 Монетизация
**Stars** (витрина, 3 якоря ≈ 0,99 / 4,99 / 19,99 $-эквивалент, средний завышен по ценности): сезонный пропуск,
косметика сетки/питомцев, «детали» для улья, ускорение банка. **Подписка** = сезон + 1 энергия/час
(`createInvoiceLink` + `subscription_period`). **Rewarded-заглушки** — 3–5 показов на сессию, максимум 10–15 в день:
оживить забег, ×2 оффлайн-сбор, +1 модификатор, починить серию; **никогда как единственная награда за прогресс**;
сегмент «вероятный плательщик» rewarded-офферов не видит. Никаких внешних платёжек, токенов и обещаний выплат.

### 6.6 Социалка и K-фактор
Инвайт `t.me/<bot>?startapp=inv_<id>`; челлендж `startapp=ch_<seed>` — обе стороны играют тот же расклад;
карточка результата — `shareMessage` (медиа, а не ссылка); лидерборд чата — по `chat_instance`;
в v2 — «вызов кнопкой прямо в сообщении» (возможно с 25.08.2026); реферальная экономика — Telegram Affiliate (Stars).
Никаких share-wall'ов.

### 6.7 First-run
0–3 с: улей уже на экране, первый мердж сделан тапом → 5–10 с: «wow» (склейка топов → вспышка + число + дроп) →
20–30 с: первая волна отбита, экран итога → 45–60 с: показан улей и цель → 60–120 с: второй забег с модификатором.
Подсказки ≤8 слов, обучение:практика 1:2,5, энергия/витрина — с 3-го забега.

### 6.8 Технические рамки
Canvas 720×1280 (portrait), DPR ≤2, **0 внешних ассетов** (процедурная графика + синтез звука), first paint ≤2 МБ;
сейв — компактный, чанками в CloudStorage (≤4096 симв./ключ) + localStorage-кэш для браузера;
`ready → expand → requestFullscreen → lockOrientation('portrait') → disableVerticalSwipes`;
звук после первого жеста; `isVersionAtLeast` для 8.0+/9.0+ фич; один origin без сторонних скриптов.

### 6.9 Правки в уже написанном коде (порядок работ при возврате к сборке)
1. `js/data.js` — энергия 100/5.5 ⇒ **8 / 1 за 4 мин**; `SHOP` из «TON» в **Stars**; добавить `D.MODIFIERS`
   (рогалик-драфт, 12–16 шт., формат «строка + число»); курс переплавки 0.55 ⇒ **≈0.5**; добавить `D.EVENTS`

### 6.10 Метрики и цели первого билда
D1 ≥ 40 %, **D7 ≥ 20–25 %**, ASL ≥ 12 мин/день, показы rewarded/юзер, **K через `start_param`** (открыл → первый
забег → шер) ≥ 0,35 с первого месяца, доля обгонов Эха ≥ 15 % забегов, платящая доля и ARPPU в Stars,
% вернувшихся после 48-ч ивента. Судить по LTV, не по регистрациям.

### 6.11 Риски
Читерские Эха (фильтр по человеческим границам + seed-верификация) · «а со мной играют боты» (никогда не выдавать
NPC за друзей) · размывание цели при дорогом/дешёвом курсе переплавки · зависимость дистрибуции от Mini App Store и
наличия Stars · `[не проверено]` доступность покупки Stars для RU → обязателен сценарий «витрина погасла, игра полна».

### 7.1 Кого вообще можно считать «топом» в Telegram-играх
* **Публичных рейтингов Telegram-мини-аппов по MAU не существует** — ни в самом Telegram, ни в архивах агрегаторов
  такой ряд не найдён (проверено по снимкам каталогов). Любые «топ-10 по аудитории» в блоге — чужие оценки.
* Каталог **TG.app** на снимок **04.10.2026**: **4290** листингов. Ценз по слагам: `ton` — **477**, `game` — **107**,
  `tap` — **41**, `merge` — **5**, `idle` — **1**. Вывод: жанровая ниша «merge + defence» в каталоге практически
  пустая, тогда как «tap-to-earn» и «ton-что-то» забиты — это подтверждает выбор жанра как отличия, а не как копии.
* Прокси-оценки популярности по отзывам (число отзывов в каталоге): **Major — 18.9K**, **Catizen — 12.3K**,
  **Blum — 9.8K**, **Hamster — 0** (т. е. хайп-пик уже прошёл и даже не реферируется). Для нас это значит:
  ориентир «как Catizen по удержанию», а не «как Hamster по всплеску».
* **ton.app** на снимок **01.11.2026**: TON **$1.22**, **27-е** место по капитализации. Курса «в Internal Token» для
  нашей экономики нет сознательно: экономика только в Stars и внутриигровой валюте.

### 7.2 Stars и RU-регион
* Дата запуска Stars — **06.06.2024** (официальный блог), вывод разработчиком — в TON через Fragment **через 21 день**.
* В `core.telegram.org/bots/payments-stars` **нет ни одного упоминания регионов/стран** ⇒ формальных запретов нет,
  но и подтверждения, что RU-пользователь может купить Stars, из документации не следует: статус покупки
  **[не проверено]**. Реализовано: `NH.Store.available() === false` → затемнённая витрина + `D.SHOP.regionLockedText`,
  дальше трафик уходит на rewarded-заглушку; игра при этом не теряет ни одного экрана.

### 7.3 Дистрибуция: Mini App Store
* Во вкладке **Apps** действует правило (снимок документации от **27.10.2026**): *«Successful bots … accept payments
  in Telegram Stars may be featured in the Telegram Mini App Store»* — то есть **наличие Stars-платежей является
  declared-сигналом для фичеринга**, публичной формулы ранжирования и формы подачи заявки нет.
* Риск дистрибуции стал осязаем: **03.08.2026 Apple кратко удалила Telegram из App Store**. Отсюда требование к
  билду: никакой критичной функциональности, которая ломается без одного контейнера (у нас всё статично, бэкенд —
  опция).
* Монетизационная рамка Telegram Ads для будущего паблишинга: «**1 billion users / 1 trillion views**»,
  «**50% of revenue … to channel owners**», оплата рекламы в **Gram** — полезно при покупке трафика на чужих каналах.
