# НЕОНОВЫЙ УЛЕЙ / NEON HIVE — Telegram Mini App

Гибрид **merge-2 × tower defence × roguelite** с асинхронным PvP-«Эхом».
Портрет 9:16, логический холст **720×1280**, RU-интерфейс.
Ноль внешних зависимостей и ноль ассетов: графика — процедурный Canvas2D, звук — WebAudio.
Код работает по `file://`, без сборщика и без npm.

Обоснование продукта, рынка и механик: [docs/RESEARCH.md](docs/RESEARCH.md), витрина/тренды: [docs/MARKET.md](docs/MARKET.md).

## Локальный запуск

```powershell
# вариант 1: просто открыть файл
start index.html

# вариант 2: статический сервер (нужен для теста Telegram-домена)
python -m http.server 8080
```

Отладочные параметры URL: `?q=0|1|2` — качество рендера (0.6/0.82/1), `?seed=hivetest` — фиксированный забег, `?mobile=0|1` — включить/выключить мобильную ветку платформы (портретный страж и фуллскрин по тапу) на десктопе.

## Ключевые механики

* **Соты (merge-2).** Тап по реактору за энергию → сотовая сетка 4×4; одинаковые ранги сливаются (до 10-го).
* **Дорожки.** Каждый столбец сетки = дорожка обороны: юнит стреляет только по своей линии.
* **Выдвижение в строй.** Перетаскивание юнита на стену: +40 % темпа и приём одного прорыва (трескается −1 ранг, гибнет только при 0-м).
* **Расщепление.** Юнит ≥4 ранга или мутант → две единицы рангом ниже + бросок мутации (превью + подтверждение).
* **Переплавка.** Возврат 50 % энергии (`RECRACY_RATE`).
* **Эхо (асинхронное PvP).** Записанный «призрак» реального забега друга: бейдж «человек», живая шкала отставания, карточка для шаринга, `<code>ch_&lt;seed&gt;</code>`-челлендж по диплинку.
* **Roguelite-драфт.** После победы — 1 модификатор из трёх, цепочка до 4 штук живёт «до пробоя» (до поражения).
* **Мета.** Улей (апгрейты), коллекция/кокон, задания + серия + сезонный пропуск, лига из 8 игроков с ротацией 3 дня, клан = группа Telegram (`chat_instance`), престиж.
* **Энергия — нектар:** 8 макс., 1 шт. / 4 мин; забег 1, осада 2, Эхо бесплатно. У реактора внутри забега своя энергия (100).

## Деплой

1. Статика на HTTPS (Cloudflare Pages / Vercel / Netlify / свой nginx). Билд не нужен — залить репозиторий как есть.
2. BotFather: `/newbot` → `/newapp` или `/setappurl`, домен должен быть **HTTPS** и принадлежать боту.
3. Ссылка на приложение: `https://t.me/NeonHiveGameBot/app` (имя бота в `NH.CFG.bot`, [js/services.js](js/services.js)).
4. Для deep-link'ов: `?startapp=inv_<id>` / `?startapp=ch_<seed>` — парсер в `NH.Share.parse`.
5. Обязательные права в `tg-web-app` исполняются в `TG.init()`, каждое под `isVersionAtLeast`: `ready() → expand() → цвета → disableVerticalSwipes() (8.0+)`, затем портрет и полный экран — см. следующий раздел. **`WebApp.init()` не вызывается никогда.**

## Портрет и полный экран

Игра рисуется на холсте 720×1280, поэтому портрет обязателен, а раздувание окна на десктопе не нужно. Логика целиком в [js/platform.js](js/platform.js) (`TG.enforcePortrait`, `TG.requestFS`), оверлей — инлайн-стили и разметка `#rotate` в [index.html](index.html).

* **Три уровня защиты от ландшафта.** 1) CSS-страховка `@media (orientation: landscape) and (hover: none) and (pointer: coarse)` показывает оверлей ещё до старта JS; как только JS поднялся, на `<html>` вешается `orientation-guard-ready`, и дальше рулит только класс `.visible`. 2) `screen.orientation.lock('portrait')` + приватное событие клиента `web_app_toggle_orientation_lock {locked:true}`. 3) Публичный `lockOrientation('portrait')` (7.7+).
* **Парадокс блокировки:** в ландшафте ориентация **разблокируется** (`locked:false`, `orientation.unlock()`), иначе пользователь физически не сможет повернуть телефон обратно. Блокировка возвращается в портрете.
* **Переворот не роняет забег:** при переходе в ландшафт активный забег ставится на паузу (`nh:pause`), под оверлеем остаётся экран паузы.
* **Пересчёт по всем событиям:** `orientationchange` (повторно через 50 и 250 мс), `viewportChanged`, `safeAreaChanged`, `contentSafeAreaChanged`, `fullscreenChanged`, `resize` — каждый зовёт `enforcePortrait` + `TG.viewport()` + `R.resize()`.
* **Полный экран только по жесту.** `requestFullscreen()` при старте клиент игнорирует, поэтому на мобильном он запрашивается с первого `pointerdown` и только если телефон уже в портрете: `web_app_expand` + `web_app_request_fullscreen` + публичный `requestFullscreen()` (8.0+, если `!isFullscreen`). Событие `fullscreenFailed` пишется в консоль.
* **Десктоп — наоборот:** если это не мобильный клиент, отправляется `web_app_exit_fullscreen` (в 0, 150 и 500 мс) и вызывается `exitFullscreen()` — Telegram Desktop не должен разворачиваться на весь экран.
* **Приватный протокол.** Событий `web_app_*` нет в публичном SDK, они уходят через `TG.sendEvent`: `TelegramWebviewProxy.postEvent` → `window.external.invoke` → `parent.postMessage`, по убыванию приоритета.

## Бэкенд-контракт (опционально)

Игра полностью играбельна **без** бэкенда: сейв уходит в `CloudStorage` (чанки по 3400 симв. под лимит 4096), лидерборды и «Эхо» — детерминированная симуляция по `seed`.
Чтобы включить кросс-девайс-сейв, Stars-витрину и реальные лидерборды, поднять три ручку и указать `NH.CFG.api`:

| Метод | Тело | Ответ |
|---|---|---|
| `POST /storage/set` | `{ user_id, key, value }` | `{ ok: true }` |
| `POST /storage/get` | `{ user_id, keys: [] }` | `{ values: { key: value } }` |
| `POST /invoice` | `{ user_id, sku, amount }` | `{ ok, payload, bot_invoice_url?, min_start_parameter? }` |
| `GET /leaderboard?week=` | — | `{ rows: [{ name, score, me? }] }` |

* `sku` — id из `D.SHOP` (`orbs|400`, `pass`, `starter`, `nectar`, `streak`).
* Вызов Stars — только `currency: "XTR"` (`NH.Store.buyItem` → `TG.pay`); TON Connect не используется.
* Если `NH.Store.available() === false`, витрина затемняется и показывает `D.SHOP.regionLockedText`, а rewarded-офферы остаются доступным путём (для плательщиков `S.s.payer = 1` — офферы скрываются, бюджет ≤15/день и ≤5/сессию).
* `user_id` брать из проверенного `initData` (серверная валидация `secret_key`), не из query-параметров.

## Тесты

`node --check js/*.js` — синтаксис.
Браузерный симулятор игрока: [qa-bot.js](qa-bot.js) (**только для тестов**, в `index.html` не подключается):

```js
// в консоли страницы
await import('qa-bot.js');            // или подключить <script> вручную
window.BOT3();                        // полный забег «как человек»: спавн, слияния по дорожкам, строй
```

Ожидаемый баланс (сбор 4 прогонов, январь 2026): победа на 8-й волне за 110–119 с, 2–9 прорывов; жадная стратегия «качать один столбец» проигрывает на 6–7 волне — это и есть температурный градиент навыка.

## Известные ограничения

* Без Telegram-контейнера `window.Telegram.WebApp` отсутствует: сейв живёт в `localStorage`, покупки отключены, всё остальное работает.
* `chat_instance` доступен только при запуске из группы — вне группы клан показывает локальный сид-лист.
* Числа в отчётах без ссылки помечены `[не проверено]`.
